DNS and CDN

CDNs like Akamai send you to a server near the DNS resolver that asked, so a resolver far away, or one that hides where you are, can send you to a distant server. Each resolver looks up the names below and the addresses it hands out are pinged: the resolver whose answers are closest to you is first.
